# Security policy

cybertrain-postal is pre-alpha and has not had an independent security review.

## Reporting a vulnerability

Please report vulnerabilities through GitHub's Private Vulnerability
Reporting (this repository's Security tab → "Report a vulnerability"), not
in a public issue.

In scope: the library (`cybertrain/postal/`): message and header building,
the SMTP client, TLS and authentication handling, and the on-disk spool.

We aim to answer within 7 days. Please give us time to ship a fix before you
publish the details.
